# Yuntao Min — Personal Website

Personal website: https://houte1186.github.io/

This static website is prepared for the CSI205TC Networking and Distributed Computing GitHub Pages exercise. It uses plain HTML, CSS and JavaScript, with no build step or third-party runtime dependencies.

## Files

- `index.html`: page structure and introduction, projects, notes and contact sections.
- `style.css`: original colours, typography, layout and responsive styles.
- `main.js`: mobile navigation, project and note dialogs, and public contact configuration.
- `favicon.svg`: original YM icon.
- `.nojekyll`: serve the static files without Jekyll processing.

## Preview and edit

Open `index.html` in a modern browser, or serve this folder with a static HTTP server. Edit the existing sections in `index.html`, and the note contents and public contact details in `main.js`. Leave the email empty unless you want to publish an address. Do not add passwords, access tokens or API keys.

## GitHub Pages

The repository is `houte1186/houte1186.github.io`. Pages publishes `main` from `/ (root)`. All asset paths are relative to `index.html`. Pushing changes to `main` triggers publication; check the Pages build and deployment workflow and then the public site.
